# Frontend transition notes

`crm-ui.js` — единый исполняемый снимок существующего интерфейса. Он консолидирует исходный порядок `app.js` и всех patch-файлов, поэтому сохраняет согласованный UX и старые inline handlers.

Для новой работы действует правило:

- визуальные страницы и обработчики — `src/frontend/pages`;
- повторно используемые шаблоны/контролы — `src/frontend/components`;
- расчёты и финансовые инварианты — только `src/domain`;
- HTTP и преобразование DTO — только `src/data`;
- CSS — `src/ui`.

Не добавлять новые `v*.js`, глобальные переопределения или прямые SQL/DB credentials. При подключении backend переносить один раздел за раз за `ApiClient`, сохраняя DOM/классы до прохождения browser regression.
