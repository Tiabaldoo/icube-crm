# iCube CRM

Интерактивный визуальный прототип CRM v1 для iCubeRobots.

- Тестовые данные и локальное состояние.
- Без Supabase, PostgreSQL, backend и настоящей авторизации.
- Директорский интерфейс — desktop-first, преподавательский — mobile-first.
- Реализованы сценарии разделов 46–49 ТЗ.
- Остальная бизнес-логика ТЗ учтена в структуре прототипа.

GitHub Pages: https://tiabaldoo.github.io/icube-crm/
