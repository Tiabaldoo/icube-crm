# iCube CRM

iCube CRM находится на переходном этапе между браузерным прототипом и серверной CRM. Текущий интерфейс сохранён как статическое приложение, критические финансовые правила вынесены в проверяемый доменный модуль, а в репозитории подготовлены схема MySQL, система миграций, API-клиент и каркас собственного backend.

Сервер, домены и настоящая база данных на этом этапе не используются. В браузерной версии данные по-прежнему существуют только до перезагрузки страницы.

## Быстрый запуск текущего интерфейса

Откройте `index.html` через любой статический HTTP-сервер. Точка входа подключает:

- `src/frontend/crm-ui.js` — сохранённый рабочий интерфейс директора и преподавателя;
- `src/ui/styles.css` — единый desktop/mobile каскад;
- `src/domain/business-rules.cjs` — чистые финансовые и расчётные правила, используемые тестами и предназначенные для backend;
- `src/data/api-client.mjs` — будущая граница frontend → `/api/v1`.

## Проверки

Требуется Node.js 22 или новее.

```bash
npm test
npm run check
```

Тесты не требуют MySQL и не меняют данные. Backend-зависимости понадобятся только на следующем этапе, когда начнётся реализация и локальный запуск API.

## Основные каталоги

```text
backend/src/                 каркас собственного API
database/migrations/         неизменяемые последовательные миграции MySQL
database/migrate.mjs         миграционный runner
src/data/                    доступ frontend к данным через API
src/domain/                  бизнес-правила без DOM и базы данных
src/frontend/                страницы и действия текущего интерфейса
src/ui/                      общий визуальный слой и mobile-правила
tests/                       автоматические регрессионные тесты
```

Текущая GitHub Pages-сборка остаётся только демонстрацией прототипа. Она не является production CRM и не должна получать секреты или прямой доступ к MySQL.
