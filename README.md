# iCube CRM

iCube CRM находится на переходном этапе между браузерным прототипом и серверной CRM. Текущий интерфейс сохранён как статическое приложение, а справочники, дети, оплаты, занятия, посещения, баланс и зарплата уже подключены к собственному MySQL/API.

Frontend получает подключённые сущности из `/api/v1`; MySQL является их источником истины. Директор и преподаватель входят через серверные 30-дневные сессии. Оплаты, возвраты, баланс, переносы, занятия, фотографии занятий, партнёрский live-расчёт и статистика уже используют backend; фиксация партнёрского расчёта остаётся следующим срезом.

## Быстрый запуск текущего интерфейса

Frontend должен обслуживаться по HTTPS на том же origin, что и `/api/v1`; без запущенного API он покажет экран входа. Точка входа подключает:

- `src/frontend/crm-ui.js` — сохранённый рабочий интерфейс директора и преподавателя;
- `src/ui/styles.css` — единый desktop/mobile каскад;
- `src/domain/business-rules.cjs` и `backend/src/lesson-rules.mjs` — проверяемые финансовые и расчётные правила;
- `src/data/api-client.mjs` — граница frontend → `/api/v1`.
- `src/frontend/lesson-photos.mjs` — оптимизация фото, защищённая загрузка и offline-очередь IndexedDB.

## Проверки

Требуется Node.js 22 или новее.

```bash
npm test
npm run check
```

Тесты не требуют MySQL и не меняют данные. Для запуска API нужны настройки test/development из `.env`.

## Основные каталоги

```text
backend/src/                 каркас собственного API
database/migrations/         неизменяемые последовательные миграции MySQL
database/migrate.mjs         миграционный runner
src/data/                    доступ frontend к данным через API
src/domain/                  бизнес-правила без DOM и базы данных
src/frontend/                страницы и действия текущего интерфейса
src/ui/                      общий визуальный слой и mobile-правила
tests/                       автоматические регрессионные тесты
```

Текущая GitHub Pages-сборка остаётся только демонстрацией прототипа. Она не является production CRM и не должна получать секреты или прямой доступ к MySQL.
